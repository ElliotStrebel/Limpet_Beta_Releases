# Limpet Beta

Limpet moves selected apps and files to an external drive to free space on your Mac, with controls to bring them back when needed. Keep the drive connected while using offloaded items.

## Download and install

[Download a Limpet beta](https://github.com/ElliotStrebel/Limpet_Beta_Releases/releases)

1. Open the most recent numbered beta release and download its **Limpet-Beta-…​.dmg** file. The `beta-feed` release is for the updater.
2. Open the disk image and drag **Limpet Beta** into **Applications**.
3. Launch Limpet Beta from Applications and connect your external drive.

Requires an **Apple silicon Mac running macOS 26.1 or later**. Intel Macs are not supported by this beta.

## Updates

Limpet checks for updates automatically when that option is enabled. You can also choose **Check for Updates…** from the app menu or Settings. Updates download inside the app and ask before installing. Restarting waits for active transfers to finish.

The app and installer are signed with Developer ID and notarized by Apple. The update feed and downloads also have dedicated update signatures.

This repository contains compiled beta downloads and installation instructions. The app’s source code is kept separately in a private repository.
