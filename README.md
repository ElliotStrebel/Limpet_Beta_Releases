# Limpet Beta

Limpet moves selected apps and files to an external drive to free space on your Mac, with controls to bring them back when needed. Keep the drive connected while using offloaded items.

## Download and install

[Download a Limpet beta](https://github.com/ElliotStrebel/Limpet_Beta_Releases/releases)

1. Open the most recent numbered beta release and download its **.dmg** file.
2. Open the disk image and drag **Limpet Beta** into **Applications**.
3. Launch Limpet Beta from Applications and connect your external drive.

Requires an **Apple silicon Mac running macOS 26.1 or later**. Intel Macs are not supported by this beta.

Use **1.0.3 or newer**. Setup builds 1.0.1 and 1.0.2, and the old `beta-feed` release, are obsolete. If you installed either setup build, install a current beta manually once to connect to the working update feed.

## Updates

Limpet checks for updates automatically when that option is enabled. You can also choose **Check for Updates…** from the app menu or Settings. Updates download inside the app and ask before installing. Restarting waits for active transfers to finish. A newly published beta can take a few minutes to reach the update feed.

The app and installer are signed with Developer ID and notarized by Apple. The update feed and downloads also have dedicated update signatures.

This repository contains compiled beta downloads, the signed update feed and installation instructions. The app’s source code is kept separately in a private repository.
