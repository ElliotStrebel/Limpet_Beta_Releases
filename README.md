# Limpet Beta

Limpet moves selected apps and files to an external drive to free space on your Mac, with controls to bring them back when needed. Keep the drive connected while using offloaded items.

## Download and install

[Download the latest Limpet beta]([https://github.com/ElliotStrebel/Limpet_Beta_Releases/releases/latest](https://github.com/ElliotStrebel/Limpet_Beta_Releases/releases))

1. Download the latest numbered beta release’s **.dmg** file. Use **1.0.5 or newer** for this invitation-only beta.
2. Open the disk image and drag **Limpet Beta** into **Applications**.
3. Launch Limpet Beta and open **Beta Licence…** from the app menu.
4. Choose **Copy Code** and send that Mac code privately to the beta organiser.
5. Once the organiser assigns your key, paste it and choose **Activate This Mac**, or choose **Import Licence File…** to open your individual licence file.
6. Connect your external drive to start using Limpet.

Requires an **Apple silicon Mac running macOS 26.1 or later** and a writable external drive. Intel Macs are not supported by this beta.

## Your beta licence

Each tester receives an individual key that works on **one Mac**. Activation needs an internet connection and assignment by the beta organiser. Keep your key private. A key awaiting assignment cannot enable offloads yet.

Beta access lasts **30 days from assignment** and can be renewed by the organiser. Limpet checks the signed licence status at launch and periodically while open. After a successful check, offline access lasts up to **seven days**, capped by your licence’s expiry.

Recall, interrupted-transfer recovery, cleanup, safe ejection and app updates remain available if your licence expires or is revoked.

## Updates

Limpet checks for updates automatically when that option is enabled. You can also choose **Check for Updates…** from the app menu or Settings. Updates download inside the app and ask before installing. Restarting waits for active transfers to finish. A newly published beta can take a few minutes to reach the update feed.

The app and installer are signed with Developer ID and notarized by Apple. The update feed and downloads also have dedicated update signatures.

Setup builds 1.0.1 and 1.0.2, and the old `beta-feed` release, are obsolete. If you installed either setup build, install a current beta manually once to connect to the working update feed.

This repository contains compiled beta downloads, signed update and licence-status files, and installation instructions. The app’s source code is kept separately in a private repository. Licence-status files contain no activation keys, tester names or raw Mac codes.
